# 6529 Museum contribution skill

A reusable AI skill for documenting gifts and community acquisitions for the 6529 Network Museum.

Shelby asked me to write up the community acquisition of XCOPY's MAX PAIN #4188/7394. I used the Museum's Casey Reas acquisition write-up and repository submission as a starting reference, then adapted the process to a single work funded by the community. This skill captures that workflow so other contributors can use it with their own LLM.

## Get the skill

**[Read SKILL.md](6529-museum-contribution/SKILL.md)** · **[Raw Markdown](https://raw.githubusercontent.com/sonoflasg/6529-museum-contribution-skill/main/6529-museum-contribution/SKILL.md)**

Download the Markdown file and attach it to your LLM, along with your artwork, proposal, transaction links, and any approved text. If your tool supports installed skills, save the folder in its supported skill location.

Suggested prompt:

> Use this skill to help document my 6529 Network Museum acquisition. Inspect the current Museum repository and my evidence. Preserve approved wording, verify credits and sources, and prepare a contribution. My requested scope is: research, draft, prepare locally, or prepare and open the PR.

The guide covers evidence, public credits, writing, record placement, validation, and opening a GitHub pull request. It distinguishes a submitted PR from an accepted accession or a live website page.
